A world, built from scratch

A personal engine project that brings together graphics programming and systems design. Building the underlying tools creates room to explore how a world is represented, rendered and navigated.

StatusIn development
Tools & technologiesC++23 / SDL3 / OpenGL

The challenge

Large 2D worlds demand careful decisions about memory, spatial representation and rendering work. The project explores these decisions directly through a custom C++ engine.

Technical focus

The work spans render jobs, image processing, signals, pathfinding and spatial subdivision. SDL3 provides the platform layer, with OpenGL used for rendering.

Next questions

Further development explores level of detail, tiled world storage and streaming. These are engineering directions rather than claims of completed production features.
