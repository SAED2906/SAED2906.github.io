Cellular Automata

A hands-on particle simulation built in C. A grid represents the world, while SDL2 handles the window, rendering and input. The interface lets the user paint and erase materials directly.

StatusPersonal project
Tools & technologiesC / SDL2 / SDL_ttf

An interactive sandbox

The supplied main loop exposes sand, stone, water and glass selection through the number keys. A circular brush paints particles with the left mouse button and removes particles with the right button; the brush size is adjustable.

A compact engine structure

The source separates the main loop, particle handling and rendering into dedicated modules. Screen dimensions determine the particle grid, using a four-pixel scale per cell.

Timing and controls

The event loop accumulates elapsed time and uses a 60 Hz target interval for rendering. The target is a scheduling choice, not a measured performance guarantee. Escape closes the application.

        if (remove) {
            remove_particle(grid_x + i, grid_y + j);
        } else if (rand() % 3 != 0) {

        }
    }
