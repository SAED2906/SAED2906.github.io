Connecting to the game.

A C++ project focused on making API interactions straightforward from application code. The interface brings together account lookup, player identifiers and champion mastery data.

STATUSIn development
TOOLS & TECHNOLOGIESC++ / REST APIs / JSON

Interface design

The current interface supports account lookup by Riot ID and PUUID, alongside champion mastery requests. Related operations are grouped into namespaces to keep calling code readable.

Errors as part of the API

HTTP failures and JSON parsing errors need distinct handling. The interface exposes Riot errors with a status code, while standard exceptions handle parsing and type failures.

Project scope

The project is a personal learning and portfolio effort. It is not affiliated with or endorsed by Riot Games. Source links and usage documentation can be added when the repository is ready.
