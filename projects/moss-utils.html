MOSS Utils

A collection of scripts for preparing student submissions and external reference projects for MOSS comparisons. The workflow connects archive preparation, directory flattening, comparison runs and structured output.

StatusAutomation toolkit
Tools & technologiesBash / Python / MOSS

Prepare inconsistent submissions

The preparation scripts flatten nested submission directories and handle duplicate filenames with numeric suffixes. An archive extraction helper supports common archive formats; the supplied helper also removes source archives and includes Java-specific cleanup.

Coordinate two comparison workflows

The main script compares student submissions with one another, then compares each student submission against the external project collection. Results are collected into JSON with separate student-versus-student and student-versus-external sections.

Support a human review process

The automation organises code-similarity results and their report links. Similarity findings support review; the project is not an automatic determination of academic misconduct.
